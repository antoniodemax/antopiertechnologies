# Antopier Technologies — Plan Change Requests

Every removal, deferral, merge, re-order or material change to a task is a change request (CR). Nothing here is applied. A CR takes effect only after explicit CEO approval, recorded in DECISIONS.md. When approved, PLAN_LEDGER.md is updated ("Fulfilled in" and "Change" columns) so every original task and deliverable stays traceable.

**Rule for merges:** a merged task must list every original deliverable and every acceptance criterion as its own named section or checklist item. A merge is not approved if any is missing.
